# Nitro

Rennspiel aus der Vogelperspektive fürs Handy, inspiriert vom Amiga-Klassiker.

- 3 Runden gegen 3 Computer-Wagen
- Links lenken, rechts Gas und Nitro
- Nitro füllt sich nach jeder Runde etwas auf

## APK herunterladen

Jeder Push auf `main` baut die App automatisch. Die neueste Version liegt immer hier:

**https://github.com/thebiz/nitro-app/releases/latest/download/Nitro.apk**
